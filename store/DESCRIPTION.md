Title: KOReader
Vendor: MAGQ

## Short tagline

KOReader, the full-featured e-book reader, ported natively to the HP TouchPad.

## Full description

An unofficial native port of KOReader — the open-source document reader used on many e-readers — to the HP TouchPad running webOS 3.0.5 or later.

Supports EPUB, PDF, DjVu, CBZ/CBR, MOBI, FB2 and more, with:
- Adjustable fonts, margins, line spacing and page layout
- Bookmarks and highlights
- Built-in dictionary lookup
- Automatic screen rotation (tilt sensor)
- Multitouch gestures for page turns and navigation
- Adjustable screen size (DPI) to fit your preference

Put your books anywhere on the TouchPad's USB storage and open them from KOReader's file browser — no fixed folder required. Reading progress, highlights and settings are kept in a `koreader` folder on the tablet's storage and carry over across updates.

This is a community port, not affiliated with or endorsed by the KOReader project. KOReader is free and open-source software (AGPL-3.0); source for this port is available at https://github.com/MAGQ1/koreader-webos.

Requires an HP TouchPad running webOS 3.0.5 or later (tested on webOS CE 3.1.0). Not compatible with webOS phones (Pre/Pixi/Veer) — this build is TouchPad-only.
